# Local Sync Notepad

**같은 공유기에 연결한 Windows PC끼리 함께 메모를 쓰고 텍스트를 빠르게 옮기는 설치형 프로그램입니다.**

메인 데스크톱은 랜선, 노트북은 Wi-Fi로 연결해도 같은 LAN이면 사용할 수 있습니다. 계정·외부 중앙 서버·인터넷 연결을 요구하지 않습니다. 프로그램 설치 파일을 처음 다운로드할 때에는 인터넷이 필요합니다.

## 이런 상황에서 사용하세요

- 데스크톱과 노트북에서 같은 메모를 열어두고 번갈아 작업할 때
- PC 한 대에서 복사한 코드·URL·텍스트를 다른 PC에서 붙여넣고 싶을 때
- 같은 집이나 사무실에서 승인한 PC끼리 간단한 공동 문서를 쓸 때

## 주요 기능

- 입력한 변경을 바로 전달하는 공동 메모. 한글·영문·줄바꿈·선택 교체·붙여넣기·동시 수정 지원
- 연결이 끊겨도 이 PC에서 메모를 편집하고 저장. 다시 연결하면 내용을 합침
- 새 방 만들기, 짧은 방 번호, 참가용 QR 이미지, QR 이미지 불러오기
- LAN에서 자동으로 방 찾기. 실패하면 IP:포트로 수동 연결
- 방장의 최초 참가 승인·거절, 이후 신뢰 기기 자동 연결
- 기기 이름·접속 상태·마지막 연결·방장 표시, 방장의 신뢰 해제 및 제거
- 텍스트 클립보드 자동 공유와 직접 보내기, 최근 기록, 원본 기기, 재복사, 고정, 삭제
- 라이트·다크, 일반·코드 글꼴, 글자 크기, 설정 저장
- Windows 시작 시 자동 실행 옵션. 기본 OFF
- 메모를 `.txt` 파일로 내보내기

## 설치하기

대상: **Windows 10/11 64비트(x64)**. Windows ARM64 전용 설치 파일은 제공하지 않습니다.

1. [다운로드 / Releases](https://github.com/KJW2-7-6/local-sync-notepad/releases)에서 `Local-Sync-Notepad-0.1.0-Setup-x64.exe`를 받습니다.
2. 설치 파일을 실행하고 안내에 따라 설치합니다. 현재 Windows 사용자 계정에 설치합니다.
3. 바탕 화면 또는 시작 메뉴에서 **Local Sync Notepad**를 실행합니다.
4. 다른 PC에도 같은 프로그램을 설치합니다.

정식 코드 서명 인증서를 구매하지 않은 초기 버전입니다. Windows가 ‘알려지지 않은 게시자’로 표시할 수 있습니다. 공식 저장소에서 받은 파일인지 먼저 확인하세요. Windows의 보안 승인은 사용자가 직접 결정합니다. Releases에 게시되기 전 빌드는 [GitHub Actions](https://github.com/KJW2-7-6/local-sync-notepad/actions)의 성공한 실행에서 `Local-Sync-Notepad-Windows-x64` 파일 묶음을 받을 수 있습니다. GitHub 로그인 없이 내려받으려면 Releases의 공개 설치 파일을 사용하세요.

설치 파일 확인(선택): PowerShell에서 `Get-FileHash .\Local-Sync-Notepad-0.1.0-Setup-x64.exe -Algorithm SHA256`을 실행하고 함께 제공되는 `SHA256SUMS.txt`와 비교합니다.

제거는 Windows **설정 → 앱 → 설치된 앱 → Local Sync Notepad → 제거**에서 합니다. 재설치를 위해 사용자 데이터는 기본적으로 남깁니다. 프로그램을 닫고 `%APPDATA%\local-sync-notepad` 폴더를 삭제하면 저장된 메모·방·기기 키·기록도 사라집니다. 필요한 메모는 먼저 내보내세요.

## 같은 Wi-Fi/LAN에서 연결하기

1. 두 PC를 같은 공유기에 연결합니다. 데스크톱의 랜선과 노트북의 Wi-Fi 조합도 가능합니다.
2. Windows 네트워크를 **개인 네트워크**로 설정합니다. 공용·게스트 Wi-Fi는 사용하지 않는 것이 좋습니다.
3. 방을 만들 PC에서 **새 방 만들기**를 선택하고 방 이름을 입력합니다. 이 PC가 방장이 됩니다.
4. 방장의 **설정**에서 방 번호를 확인합니다.
5. 다른 PC의 첫 화면에서 번호를 입력하고 **참가 요청하기**를 누릅니다.
6. 방장 화면에 요청한 기기 이름과 확인 번호가 나타납니다. 상대 화면의 확인 번호가 같은지 확인하고 **승인**합니다.

한 번 승인한 기기는 같은 데이터 폴더와 기기 키를 사용하는 동안 다음 실행부터 자동 연결합니다. 프로그램 데이터 폴더를 다른 PC에 복제하면 안 됩니다. 각 PC는 자체 키를 처음 생성해서 사용하세요.

방장 PC가 켜져 있어야 여러 PC의 실시간 전송이 가능합니다. 방장이 꺼지면 각 PC에서 메모는 계속 편집·저장할 수 있으며, 방장이 돌아오면 합칩니다. 이미 참가한 방은 프로그램을 다시 켜도 자동으로 복원합니다.

### 검색이 안 될 때

방장 **설정 → 수동 연결 주소**에서 `192.168.0.10:48765` 같은 주소를 복사해 전달합니다. 참가 PC에서 **방 번호 + 수동 연결 주소**를 함께 입력합니다. 실제 포트는 사용 상황에 따라 달라질 수 있으므로 설정에 표시된 주소를 사용하세요.

QR도 사용할 수 있습니다. 방장 설정에서 **QR 저장**을 눌러 이미지를 전달하고 참가 PC의 **QR 이미지 불러오기**로 읽습니다. PC용 QR 프로그램에서 읽은 `localsync://join?...` 참가 링크를 방 번호 입력란에 붙여넣어도 됩니다. PC에 카메라가 없어도 번호·주소 또는 QR 이미지로 참가합니다.

인터넷이 끊겨도 공유기와 두 PC 사이의 통신이 살아 있으면 사용 가능합니다. 회사·게스트 Wi-Fi의 ‘기기 간 통신 차단’ 기능이 켜져 있으면 수동 연결도 실패할 수 있습니다.

### Windows 방화벽

방화벽 안내가 나타나면 이 프로그램의 **개인 네트워크 접근**을 허용합니다. 이미 차단했다면 **Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용**에서 이 앱의 개인 네트워크 항목을 확인하세요.

관리자가 규칙을 직접 만드는 환경은 방장의 TCP 포트(기본 48765, 설정의 실제 포트 확인)와 자동 검색용 UDP 5353을 개인 LAN 범위에서 허용합니다. Windows 방화벽 전체를 끄거나 공유기의 인터넷 포트 포워딩을 설정할 필요는 없습니다. 자세한 점검 절차는 [실제 PC 검사 안내](docs/REAL_PC_TEST.md)에 있습니다.

## 메모장 사용하기

**공동 메모** 탭에서 바로 입력합니다. 몇 초마다 문서 전체를 새로 받지 않고 변경분을 전달합니다. 한글·영문·숫자·Enter·Backspace·Delete·복사·잘라내기·붙여넣기·선택 교체를 일반 편집기처럼 사용하세요. `Ctrl+Z`로 자신의 최근 편집을 되돌릴 수 있습니다.

상단에서 맑은 고딕/Segoe UI/Arial 또는 Consolas/Cascadia Code를 선택하고 글자 크기를 바꿉니다. 설치되지 않은 글꼴은 운영체제의 대체 글꼴로 표시됩니다. **메모 내보내기** 버튼은 한글이 읽히는 UTF-8 텍스트 파일을 저장합니다.

연결 상태는 왼쪽과 문서 아래에 표시됩니다. 다른 PC와 동시에 같은 위치를 수정하면 변경을 합치지만, 문장의 의미까지 자동으로 정리하지는 않습니다. 방마다 공동 메모 하나를 제공합니다. 새 방이나 다른 방으로 이동하기 전에 필요한 메모는 내보내세요.

## 클립보드 사용하기

**클립보드** 탭에서 텍스트를 넣고 **텍스트 보내기**를 누르면 다른 PC의 기록에 나타납니다. 항목이나 **복사**를 누르면 그 PC의 시스템 클립보드에 들어갑니다.

**자동 클립보드 공유**를 켜면 복사한 텍스트를 연결된 PC에 전송하고, 수신된 텍스트를 이 PC의 클립보드에도 넣습니다. 다른 PC에서도 켜야 그 PC의 시스템 클립보드가 자동으로 바뀝니다. OFF에서도 수신된 항목은 기록에서 볼 수 있습니다. 받은 항목과 재복사한 항목은 다시 자동 전송하지 않아 반복 공유를 방지합니다.

자동 공유는 기본 OFF입니다. 비밀번호·인증 코드처럼 복사한 민감한 텍스트도 전달될 수 있으니 필요한 동안만 켜세요. 메모장에서 복사한 텍스트도 같은 규칙을 따릅니다.

항목을 고정하거나 삭제할 수 있습니다. 고정·삭제·전체 삭제는 **이 PC의 기록에만** 적용합니다. 텍스트 256KB 이하, 최근 100개, 고정 30개까지 보관합니다. 이미지·파일은 지원하지 않습니다. 끊긴 동안의 클립보드 변경은 나중에 자동 전송하지 않습니다.

## 기기 관리와 설정

- **기기 관리**에서 이 PC 이름을 저장합니다. 이름은 상대 PC에도 반영합니다.
- 방장은 다른 기기를 제거하고 신뢰를 해제할 수 있습니다. 제거 즉시 연결을 끊고 다음 접속에서 새 승인을 요구합니다.
- **설정**에서 방 이름·번호·QR·연결 주소를 확인합니다. 방장뿐 아니라 승인된 참가 PC도 공개 참가 정보를 확인할 수 있습니다.
- 라이트/다크와 글꼴은 PC별로 저장합니다. **Windows 시작 시 자동 실행**도 필요할 때 직접 켭니다.
- 앱을 닫으면 종료합니다. 이번 버전은 트레이에서 계속 실행하는 기능을 제공하지 않습니다. 동기화를 유지하려면 앱을 열어두세요.

## 보안과 저장

같은 Wi-Fi라는 이유만으로 내용을 공개하지 않습니다. 최초 방장 승인, 무작위 기기 ID와 인증 키, TLS 암호화, 저장한 방장 인증서 확인을 사용합니다. 방 번호는 검색용이며 비밀번호가 아닙니다. 첫 승인 때 두 화면의 확인 번호를 비교하세요.

Windows 설치 앱은 현재 사용자의 OS 보호 저장으로 로컬 데이터 파일을 암호화합니다. 방·승인 기기·기기 이름·메모·설정·클립보드 기록은 프로그램을 다시 실행해도 남습니다. 파일 손상 시 직전 정상 백업을 읽습니다. 같은 Windows 계정 권한의 악성 프로그램을 방어하는 전용 보안 프로그램은 아닙니다.

기기 제거는 이후 전송을 차단합니다. 이미 상대 PC에 저장된 데이터를 원격으로 삭제하지 않습니다. 기록 삭제는 보안 삭제가 아니므로 직전 백업에 내용이 남을 수 있습니다. [구조와 보안 설명](docs/ARCHITECTURE.md)에 자세한 범위를 적었습니다.

## 현재 제한사항

- Windows x64 초기 버전. 휴대폰·웹 서비스·인터넷 원격 연결은 제공하지 않습니다.
- 방장 자동 교체, 여러 방 동시 접속, 여러 메모 파일, 이미지·파일 클립보드, 시스템 트레이는 제외했습니다.
- IPv4 LAN을 지원합니다. IPv6 전용 네트워크는 지원하지 않습니다.
- 메모 UTF-8 2MB 및 내부 공동 편집 상태 4MB까지. 아주 많은 교체 이력으로 내부 상태가 커지면 먼저 내보내고 새 방을 사용할 수 있습니다.
- 전원이 갑자기 끊기면 마지막 약 120ms의 입력은 저장되지 않을 수 있습니다. 정상 종료 때는 마지막 변경을 저장합니다.
- 실제 Windows PC 두 대와 공유기의 방화벽·Wi-Fi 설정은 사용 환경에 따라 추가 검사가 필요합니다. 검증 범위는 [최종 보고서](FINAL_REPORT.md)를 확인하세요.

## 개발하거나 직접 빌드하기

일반 사용자는 설치 파일만 사용하면 됩니다. 소스를 실행할 개발자는 Node.js 24를 설치한 뒤 저장소를 다운로드하고 다음을 실행합니다.

```bash
npm ci
npm run check
npm run dev
```

Windows 설치 파일:

```bash
npm run dist:win
```

`release` 폴더에 설치 파일이 생깁니다. Windows에서 빌드하는 것을 권장합니다. Linux에서는 NSIS의 Wine 실행 조건이 추가로 필요할 수 있습니다. 클라우드 작업은 GitHub Windows 자동 빌드를 함께 사용합니다.

실제 화면 검사: `npm run build` 후 `npm run test:e2e`. Linux에서는 `xvfb-run -a npm run test:e2e`로 가상 화면을 사용합니다. 검사 프로필은 임시 폴더에만 생성하며 일반 사용자의 메모와 분리합니다.

개발 과정은 [개발 기록](DEVELOPMENT_REPORT.md), 결과와 검증 범위는 [최종 보고서](FINAL_REPORT.md)에 누적합니다.
